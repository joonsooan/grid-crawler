# Grid Crawler

<img width="1920" height="1080" alt="image" src="https://github.com/user-attachments/assets/3035a46b-24e7-4183-9101-14bb7cc5cdaa" />

2D 탑다운 턴제 게임을 함께 만들어보며, Unity로 단순히 작동하는 게임을 만드는 단계를 넘어 **수정하기 편하고 확장하기 쉬운 코드 구조**를 만드는 법을 학습합니다

<br>

> 유니티 버전 : Unity 6.3 LTS (6000.3.10f1)

<br>

> [세미나 노션 페이지](https://poolc-unity-intermediate.notion.site/Unity-3ca665ae652780ef9288de61a5ad6da2)

<br>

### 배우는 내용 ✅

- 게임 기획서의 요구사항을 읽고, 이를 토대로 **적합한 아키텍처와 자료구조를 계획**하는 연습을 합니다
- 게임 개발을 할 때 흔히 작성하는 ‘나쁜 코드’를 먼저 살펴보고, 무엇이 유지보수를 어렵게 만드는지 원인을 파악한 뒤 리팩토링하는 실습을 진행합니다
- **Rect Tilemap 환경 구축, ScriptableObject 에셋 생성** 등 Unity 에디터 관련 기능을 다룹니다
- **FSM, Interface, Coroutine, C# Event** 등 Unity 중급 내용을 학습합니다
- **싱글톤, 옵저버 패턴** 등 게임 개발에 필수적인 디자인 패턴을 적용해봅니다

<br>

### 수강 대상 🎯

- 기본적인 Unity 사용법은 알지만 그 다음 단계로 어떻게 넘어가야 할지 막막하신 분
- Unity 개발 시 유지보수가 쉬운 아키텍처를 짜는 법을 배워보고 싶으신 분

<br>

### 커리큘럼 📅

0. 기획 요구사항 분석과 아키텍처 설계

1. Grid 좌표계 설계

2. Interface 기반 상호작용

3. ScriptableObject 기반 데이터 관리

4. FSM과 Queue를 활용한 턴제 시스템

5. Event를 활용한 옵저버 패턴

6. Object Pooling 최적화

7. DOTween으로 연출 및 UX 개선

8. (Bonus) 테스트 코드 작성

9. (Bonus) 커맨드 패턴 기반 리플레이 시스템
